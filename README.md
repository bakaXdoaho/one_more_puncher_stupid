# one_more_puncher_stupid

文字打孔器小玩具：粘一段中文，选个模式，打孔.avi。程序从你的文字里挑字打孔，掉下来的字拼成一句藏在句库里的话。

灵感来自近期（2026/10 前后）网传热门打孔器小游戏，感谢作者们！

谢亲友陪伴口嗨使本玩具诞生！文件由 Claude Opus 5.5（Anthropic）编写，许多设计亦由Claude（及其训练集和查询的资料）提供，感谢前人。

当前版本近乎Claude直出，大量细节暂未来得及人工把关，如有问题十分抱歉。

## 模式

- **树人**：句子取自鲁迅作品（以《狂人日记》为主），参考维基语录「鲁迅」，共 169 句，按三组加权：《狂人日记》、人人都知道的、断章取义很好笑的。
  - 勾选"其他动物也吃"：文中的动物字（只认原字）另起一行掉下来，最多一行。
  - 字缝：纸面上挨着的"吃""人"（横、竖、斜都算）会被优先拼成"吃人"。
- **兄弟**：《火焰纹章：风花雪月》及衍生游戏中库罗德的梗。暂时只有"神鬼军师""倒吊"两条；掉下来的字整行倒吊，把手机转过来能正着读。
- **新三国**：台词参考萌娘百科「新三国梗」和新三国 Wiki（Fandom）的台词梗。
- **我偏要说**：自己写一句话（最多 20 字，默认"天生一对"），看能不能从文中拼出来；拼不出来就是"天意未必如此啊！"。
- **手动**：在画布上点字，自己打孔。

## 规则（v0.4）

1. 树人、兄弟、新三国三个模式各有一个句库，句子本身不会显示在页面上。
2. 每次按"打孔"，从句库里挑一句（一半的概率再来一句），在文中找字拼出来：
   - 优先用原字；找不到就用**同音同调**的字顶上（v0.2 允许不同声调）。
   - 至少一半的字得是原字（兄弟模式不限）。
   - 拼不全整句就用片段：片段只在词边界上起止，至少占整句一半的字，不以虚字或"你我他"结尾；四个字以内的句子不拆。
   - 树人模式更严：片段只能是完整的分句（以标点为界），不从分句中间切。
   - 不留空孔：缺字就换一句。
3. 我偏要说模式只认整句，不拆片段，也不加第二句。规则同上（同音同调、至少一半原字）；字母和数字必须原样找到。
4. 一句也拼不出时的提示：
   - 树人：“我实在没有说过这样一句话”
   - 兄弟：这里找不到神鬼军师
   - 新三国：这段不似正史
   - 我偏要说：天意未必如此啊！
5. 每次结果随机，"重播"重放同一句。
6. 目前只支持中文。

## 改句库

编辑 `one_more_puncher_stupid_gen.py` 顶部的 `BANKS`（句子, 权重），然后运行：

```
pip install pypinyin
python3 one_more_puncher_stupid_gen.py <jieba 的 dict.txt> one_more_puncher_stupid.html
```

`dict.txt` 来自 jieba 的源码包（`pip download jieba --no-binary :all:`，解压后在 `jieba/dict.txt`），用来算常用字和给句子分词。

- pypinyin 偶尔把多音字注错（比如"你那里配姓赵"的"那"），在 `READINGS` 里按"句子 → {字: 读音}"纠正。
- 脚本还会生成 `TONE_GROUPS`：3500 个常用字的同音同调分组，供我偏要说模式查替补字。用户的句子没有上下文，所以每个字只按最常见的读音分组。
