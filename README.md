# one_more_puncher_stupid

文字打孔器小玩具：粘一段中文，选个模式，打孔.avi。程序从你的文字里挑字打孔，掉下来的字拼成一句藏在句库里的话。

灵感来自近期（2026/10 前后）网传热门打孔器小游戏，感谢作者们！

谢亲友陪伴口嗨使本玩具诞生！文件由 Claude Opus 5.5（Anthropic）编写，许多设计亦由Claude（及其训练集和查询的资料）提供，感谢前人。

当前版本近乎Claude直出，大量细节暂未来得及人工把关，如有问题十分抱歉。

| `one_more_puncher_stupid_gen.py` | 生成句库和谐音表，写进 HTML 里 `/*@@DATA*/ … /*@@END*/` 之间 |

## 模式

- **树人**：句子取自《狂人日记》（1918，已进入公有领域）。
- **兄弟**：火焰纹章：风花雪月库罗德的梗。暂时只有"神鬼军师""倒吊"两条，掉下来的字整行倒吊（把手机转过来能正着读）。
- **新三国**：台词参考萌娘百科「新三国梗」和新三国 Wiki（Fandom）的台词梗。
- **手动**：在画布上点字，自己打孔。

## 规则（v0.3）

1. 每个模式有一个句库，句子本身不会显示在页面上。
2. 每次按"打孔"，从句库里挑一句（一半的概率再来一句），在文中找字拼出来：
   - 优先用原字；找不到就用**同音同调**的字顶上（v0.2 允许不同声调）。
   - 至少一半的字得是原字（兄弟模式不限）。
   - 拼不全整句就用片段：片段只在词边界上起止，至少占整句一半的字，不以虚字或"你我他"结尾；四个字以内的句子不拆。
   - 不留空孔：缺字就换一句。
3. 每次结果随机，"重播"重放同一句。
4. 目前只支持中文。

## 改句库

编辑 `one_more_puncher_stupid_gen.py` 顶部的 `BANKS`（句子, 权重），然后运行：

```
pip install pypinyin
python3 one_more_puncher_stupid_gen.py <jieba 的 dict.txt> one_more_puncher_stupid_v3.html
```

`dict.txt` 来自 jieba 的源码包（`pip download jieba --no-binary :all:`，解压后在 `jieba/dict.txt`），用来算常用字和给句子分词。
